# SlimTrack

Дневник похудения для iPhone: калории, БЖУ, вода, вес, график прогресса и **ИИ, который считает калории по фото и раскладывает остаток дня по меню**.

Ставится через Safari → «На экран Домой». Без App Store, без Xcode, без денег. Хостинг — GitHub Pages (бесплатно).

## Что внутри

- **Онбординг** — 7 шагов: пол, возраст, рост, вес, цель, активность, темп → расчёт нормы по формуле Миффлина–Сан Жеора
- **Главный экран** — три кольца Activity Rings в стиле Apple Health: калории (красное), белок (зелёное), вода (синее)
- **«Что мне съесть?»** — ИИ берёт остаток калорий и собирает меню **только из твоей базы продуктов**. Приложение само пересчитывает калории по локальной БД, цифры точные
- **«Сфоткать еду»** — ИИ определяет блюдо, граммы и КБЖУ
- **Чат** — ИИ видит профиль, норму и всё, что съедено за день
- **Прогресс** — график веса, серия, темп, история взвешиваний
- **Дневник** — все приёмы пищи по дням

## Как запустить

### 1. Залить на GitHub Pages

1. Создай репозиторий на [github.com/new](https://github.com/new), назови `slimtrack`, поставь **Public**
2. Залей туда всю папку `slim-pwa` (drag-and-drop файлов прямо на странице репо)
3. Зайди в **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, Folder: **/ (root)** → **Save**
4. Через минуту приложение будет на `https://<твой-ник>.github.io/slimtrack/`

### 2. Поставить на iPhone

Открой ссылку **в Safari** (не Chrome):

1. Кнопка «Поделиться» (квадрат со стрелкой внизу экрана)
2. Прокрутить вниз → **«На экран Домой»**
3. «Добавить»

Готово: иконка на рабочем столе, открывается на весь экран без адресной строки, работает офлайн.

### 3. Подключить ИИ

При первом открытии приложение покажет «Нужен ключ» в карточке ИИ. Это нормально — ИИ работает на твоём собственном OpenRouter-ключе (это платный сервис, но дёшево). Ключ вводится один раз в **Профиль → ИИ** и хранится только в IndexedDB твоего браузера, никуда не уходит.

**Как получить ключ за 30 секунд:**

1. Зайди на [openrouter.ai/keys](https://openrouter.ai/keys)
2. **Create Key** → скопируй ключ
3. **Add Credits** → пополни на $5 (хватит на месяцы)
4. В приложении: **Профиль → ИИ → вставь ключ → Сохранить → Проверить**

Модель по умолчанию: **`qwen/qwen3.7-flash`** — она и для чата, и для распознавания еды по фото (умеет принимать картинки).

## Формулы

- **BMR** — Миффлин–Сан Жеор: `10×вес + 6.25×рост − 5×возраст (+5 муж / −161 жен)`
- **TDEE** = BMR × коэффициент активности
- **Цель** = TDEE − дефицит (не ниже 1200 ккал)
- **Белок** = 1.8 г/кг, **жиры** = 28% от калорий

Приложение не медицинское. При заболеваниях, беременности, приёме лекарств — сначала врач.
